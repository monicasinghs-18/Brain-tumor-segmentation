
Brain Tumor Segmentation

Project Overview

Brain Tumor Segmentation is an image-processing-based project designed to identify and highlight tumor regions in MRI brain images. The system uses image preprocessing, threshold-based segmentation, contour detection, and CNN-based classification.

Objectives

- To process MRI brain images.
- To reduce noise and improve image quality.
- To identify and segment suspected tumor regions.
- To highlight tumor regions using image overlays.
- To classify brain tumor images using a Convolutional Neural Network (CNN).

Technologies Used

- Python
- OpenCV
- NumPy
- Matplotlib
- TensorFlow / Keras
- Google Colab

Methodology

1. Image Acquisition
2. Image Preprocessing
3. Noise Reduction and Normalization
4. Tumor Segmentation
5. Contour Detection
6. CNN-Based Classification
7. Result Visualization

Applications

- MRI image analysis
- Brain tumor research
- Medical image processing
- Computer-aided diagnosis research
